# AI Hub v3

AI 工具整合 + 创作社区 交互原型（单文件，双击 index.html 即可运行）

## 目录
- index.html        主文件（含工具目录、作品社区、登录、六维评价、评论）
- logo_cutout.png   去绿幕透明底 Logo
- logo_preview_white.png / logo_preview_dark.png  预览图

## 已实现
- AI 工具分类检索（8 类 / 20+ 工具），点击卡片进入详情页
- 工具详情页：官网地址、六维雷达图（任务理解/工具使用/记忆上下文/推理决策/可靠安全/交互进化）、平均分、6 条维度分、评论区
- 六维打分评价：登录后 1-5 星逐项打分，漏打分不允许提交
- 作品社区：生图/视频/建模/游戏 分区，支持图片/视频/音频/文本/游戏软件上传（文件名占位）
- 每件作品带提示词（一键复制）+ 使用工具 + 体验链接
- 点赞 / 收藏 / 分享 / 嵌套评论 / 1-5 星评分
- 排序：最新 / 最热 / 评分最高 / 最多赞
- 个人主页：我的作品 / 我的收藏 / 我赞过的 / 我的评价
- 登录注册（演示账号 demo / 1234）

## 说明
数据存浏览器 localStorage，仅本机可见；文件上传为占位，未接后端存储。
